## Phase Goal

**As a** lifter with real data on my phone, **I want to** back up and restore my data and see my history, charts and a quick morning body check-in, **so that** nothing is lost and I can see my progress.

This plan delivers the "nothing is lost" half first: the riskiest and most important slice of the phase (data lives only on the phone).

<objective>
Ship the backup loop end to end: export every store as one versioned JSON file (download, plus the Android share sheet as text/plain .txt), restore it from the first screen of a wiped app with a one-line summary and one confirm, written in a single transaction. Bump the database to schema 2 with the dailyLogs store (used by the morning check-in in 02-03) so the backup format and its store list are fixed before any check-in data exists. Show "último backup há N dias" on Today and Settings and remind after 3 workouts without a backup.

Purpose: BKP-01, BKP-02, BKP-03 and ROADMAP Phase 2 success criteria 1–3. The backup file is the only redundancy this app has (PITFALLS 1–2).
Output: src/domain/backup.js (pure, tested), readStores/replaceStores and schema 2 in src/data/db.js, the #/backup screen, the restore entry on onboarding, the reminder on Today/Settings, E2E 08-backup, re-stamped sw.js. Version stays 0.2.1 (02-03 publishes 0.3.0).
</objective>
