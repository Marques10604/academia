1. src/version.js: export const APP_VERSION = '0.1.0' (the single place to bump the version).

2. sw.js (classic script at the repo root, hand-written, no Workbox). Line 1 holds const VERSION = '0.1.0'; and the next line const CACHE = 'academia-' + VERSION;. Then an ASSETS array literal between the comment lines // ASSETS-START and // ASSETS-END. install: event.waitUntil(caches.open(CACHE).then(c => c.addAll(ASSETS))), which is atomic: a version is either fully cached or not installed. activate: delete every cache whose name starts with 'academia-' and is not CACHE. fetch: ignore non-GET and cross-origin requests (YouTube links are outbound and never intercepted); respond with caches.match(request, {ignoreSearch: true}); on a miss for request.mode 'navigate' respond with caches.match('./index.html'); otherwise fall back to fetch(request). Do NOT call the ServiceWorkerGlobalScope method that force-activates a waiting worker, and do NOT claim clients. A new version must wait until every app window is closed (FUND-03: never swap code mid-workout). This is the user's lean rule: no update toast, no forced-update button.

3. tools/stamp-sw.mjs (dev only, node:fs and node:path): read APP_VERSION from src/version.js with a regex, then rewrite sw.js. Replace the VERSION line and, between the ASSETS markers, write a sorted list of the shipped files that exist right now: './' and './index.html' (only when index.html exists), styles.css, manifest.webmanifest, every file under icons/ and every file under src/ (recursive), each as './relative/path' with forward slashes. Never list tools/, test/, .planning/, .claude/, package.json or .git. With --check it writes nothing and exits 1 when sw.js differs from what it would write ("sw.js desatualizado: rode node tools/stamp-sw.mjs"), else exits 0. Run it once now. Its asset list depends on which app files exist at that moment (01-01 adds src/ files in parallel), so this plan verifies only its own deterministic output and never gates on --check; 01-03 re-stamps after both wave-1 plans and gates on --check, and 01-06 does the same before 0.2.0.
