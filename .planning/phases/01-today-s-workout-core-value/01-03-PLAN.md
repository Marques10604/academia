## Phase Goal

**As a** gym beginner, **I want to** open the installed app offline, see today's workout, log each set in seconds and be told what load to use next, **so that** I always know what to do and my loads progress automatically.

This plan closes the core loop (finish → summary → next workout), adds the first-open medical notice and Settings, registers the service worker and publishes 0.1.0 to the permanent URL so the user can install it on the phone.
