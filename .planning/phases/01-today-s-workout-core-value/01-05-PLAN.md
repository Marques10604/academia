## Phase Goal

**As a** gym beginner, **I want to** open the installed app offline, see today's workout, log each set in seconds and be told what load to use next, **so that** I always know what to do and my loads progress automatically.

This plan delivers "log each set in seconds" with rest timer, wake lock and the finish summary.

## Scope note

10 files, at the checker's 10-file line: the draft, timer and records unit tests share one file (test/logging.test.js), and two files are this plan's E2E scenarios. The parallel plan 01-04 owns Today, the router and the exercise data, so this plan never touches them.

<objective>
Turn the skeleton workout screen into the real one-handed logger: prefilled 1-tap sets with +/− steppers, the previous session's result inline, "leve / no ponto / pesado" on the last set, undo, a guided warm-up on the first exercise, an automatic rest timer computed from a saved end time with vibration/beep, a screen wake lock, and a finish summary with loads and personal records.

Purpose: Pitfall 9 (slow logging kills the habit) and Pitfall 6 (lost workouts) are the main threats to the Core Value. This plan is the hot path used dozens of times per session.

</objective>
