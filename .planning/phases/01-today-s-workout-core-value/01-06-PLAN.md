## Phase Goal

**As a** gym beginner, **I want to** open the installed app offline, see today's workout, log each set in seconds and be told what load to use next, **so that** I always know what to do and my loads progress automatically.

This plan closes the phase: guided starting-load discovery, per-exercise increments, then publishing 0.2.0 for the real-phone test.

<objective>
Add the guided calibration ramp to the workout (sets of 10, "Quantas repetições ainda sobravam?", automatic next ramp load, working load chosen), show phase and effort on the workout card, let the user set each exercise's increment, then bump to 0.2.0, re-stamp the service worker with every new file, publish, and run the consolidated real-phone check.

Purpose: an absolute beginner does not know his starting loads (CARGA-01). Equipment steps differ per gym (CARGA-06). The phone check closes all device-only success criteria.
Output: calibrationStep plus tests, ramp actions and UI, the increment selector, the E2E scenario 05-calibration, version 0.2.0 live.
</objective>
