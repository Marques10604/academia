## Phase Goal

**As a** gym beginner, **I want to** open the installed app offline, see today's workout, log each set in seconds and be told what load to use next, **so that** I always know what to do and my loads progress automatically.

This plan delivers "how to do each exercise" and "with what load" on the Today screen.
