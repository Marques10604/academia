## Phase Goal

**As a** user who wants more than a logger, **I want to** track protein lightly, set goals, get a morning-alarm guide, take progress photos and ask an AI about my data, **so that** I stay consistent and understand my progress.

This plan delivers the copyable AI report (IA-01) and the morning-alarm guide with the optional calendar file (META-04), updates the rescue kit's file map and publishes the whole phase as 0.5.0.

<objective>
Add "Gerar relatório para IA" (Config → #/relatorio): a plain pt-BR summary of the user's own data with a ready question, copied in one tap or shared, to paste into any free AI. Add "Lembrete matinal" (Config → #/lembrete): three illustrated steps to create a repeating "Treino" alarm in the Android Clock, plus an optional downloadable .ics with a daily recurring event and an alarm at a chosen time. Then list the new files in KIT-SOCORRO-IA.md, bump to 0.5.0, re-stamp the service worker, pass every gate and publish with the ff-only procedure.

Purpose: ROADMAP Phase 3 success criteria 3 and 5. STACK.md "Platform Capabilities" and PITFALLS 7: a PWA without a server cannot ring at 07:00 (Notification Triggers ended, push needs a server), so the honest reminder is the phone's own alarm or calendar. The AI report keeps "IA sem servidor": no key, no network call, the user decides what to paste.
Output: src/domain/report.js + tests, src/ui/report.js, src/domain/reminder.js + tests, src/ui/reminder.js, two routes, two Config cards, E2E 15-report-alarm, kit file map, version 0.5.0 live.
